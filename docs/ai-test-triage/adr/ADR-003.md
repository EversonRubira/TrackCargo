# ADR-003 - Graceful Degradation, Retry, and Timeout

**Status:** Accepted

## Context
AI Test Triage is auxiliary. Claude unavailability, timeout, or malformed output cannot obscure the original Java failure.

## Decision
Allow at most 2 attempts with an initial timeout of 30 seconds per attempt. Retry transient provider failures, timeout, or structurally invalid output. After final failure, emit `TRIAGE FAILED` and preserve the original test result/evidence.

## Consequences
- bounded waiting;
- recovery opportunity for transient failures;
- worst case can add about 60 seconds of provider wait before ancillary overhead;
- timeout must be revisited using observed latency.
