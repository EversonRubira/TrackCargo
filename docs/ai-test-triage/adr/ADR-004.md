# ADR-004 - Failure Limit Now; Clustering/Deduplication Later

**Status:** Accepted

## Context
One root cause may break many tests. Calling Claude per failure can create redundant diagnoses and excessive cost/latency.

## Decision
V1 analyzes at most 5 distinct failed tests per pipeline. It will not implement failure clustering/deduplication yet. Observability and eval data will determine whether grouping failures is worth the added complexity.

## Consequences
- simple, bounded V1;
- some failures may remain untriaged;
- future clustering can reduce duplicated calls when evidence shows a need.
