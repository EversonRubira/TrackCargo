# ADR-002 - Read-only and Human-in-the-loop

**Status:** Accepted

## Context
Giving the triage component editing, execution, or publishing authority would increase impact from incorrect diagnosis, hallucination, or prompt injection.

## Decision
V1 is read-only. Claude provides diagnosis, evidence, options, and trade-offs. A human makes the technical decision. Any implementation/remediation occurs outside AI Test Triage.

## Consequences
- applies least privilege;
- reduces prompt-injection blast radius;
- preserves human accountability;
- triage does not automatically resolve the failed test.
