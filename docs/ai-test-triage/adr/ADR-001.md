# ADR-001 - Deterministic Context Retrieval for V1

**Status:** Accepted

## Context
The LLM needs relevant code/documentation, but repository-wide context increases noise, cost, latency, and unnecessary exposure. Alternatives considered: full repository, deterministic retrieval, lexical search, RAG/embeddings, and hybrid retrieval.

## Decision
V1 uses deterministic retrieval driven by failed test name, stack trace, and explicit identifiable relationships. RAG is not introduced without evidence of need.

## Consequences
- simpler and cheaper baseline;
- predictable and testable selection;
- may miss semantically related documentation without explicit linkage;
- baseline evals determine whether hybrid/RAG retrieval is justified.
